1.1

什么是原子？

2500年前，希腊哲学家德谟克里特提出"原子"概念。直到19世纪，科学家们通过实验逐步揭开了原子的真实结构。

1803
约翰·道尔顿 John Dalton（英国）
实心球体模型
原子是不可再分的最小粒子，不能被消灭也不能被创造。同种原子质量、大小相同；化学反应中原子只以简单整数比结合。
1897
约瑟夫·汤姆生 J.J. Thomson（英国）
🍉 西瓜模型（枣糕模型）
发现原子内有带负电的电子。原子整体呈电中性，正电荷均匀分布于球体，电子像西瓜籽嵌在其中。
1911
欧内斯特·卢瑟福 Ernest Rutherford（英国）
🪐 核式结构模型
原子中心有一个极小而致密的原子核，全部正电荷（质子）和几乎全部质量集中于此；带负电的电子在核外空间绕核运动。
1913
尼尔斯·玻尔 Niels Bohr（丹麦）
轨道模型
完善卢瑟福模型——电子只能在特定轨道上绕核运动，每条轨道对应特定能量。
1932
詹姆斯·查德威克 James Chadwick（英国）
发现中子
证实原子核除了带正电的质子外，还有不带电的中子——现代原子模型基本完善。

位于原子核 · 带正电 · 质量较大

中子 Neutron
位于原子核 · 不带电 · 质量较大

e⁻

核外轨道 · 带负电 · 质量极小
高速绕原子核运动

什么是元素？

拥有相同质子数的原子属于同一种元素。目前已知超过100种元素。1869年，门捷列夫发表第一张元素周期表。

金属 vs 非金属

🔵 金属 Metal
  • ✓ 室温下为固体（汞除外）
  • ✓ 有金属光泽
  • ✓ 良好导电导热性
  • ✓ 可锻造延展
  • ✓ 元素符号在化学式左边
🟢 非金属 Non-metal
  • ✓ 固体或气体（溴是液体）
  • ✓ 不良导体
  • ✓ 无金属光泽（碘有）
  • ✓ 元素符号在化学式右边
  • ✓ 稀有气体极不活泼

分子与离子

物质不仅由原子构成，还可以由分子或离子构成。

🔗 分子 Molecule

由两个或多个原子构成的粒子。化学式表示分子中元素种类和原子数量。

H2O

相对原子质量 & 相对分子质量

原子质量极小（如氧原子仅 2.657×10⁻²⁶ kg），科学上用相对原子质量表示。分子的相对分子质量 = 各原子相对原子质量之和。
