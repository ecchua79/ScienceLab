1. 为什么短路时电流会过大？短路时电流不经过用电器，电路中只有导线，电阻几乎为零，由 I = V/R 可知电流极大，会烧坏电源，甚至引发火灾。

4.2 什么是电流？

金属里有大量自由电荷，平时杂乱无序地运动；接上电池后受到推动力，做定向移动，电荷的定向移动形成电流。

4.2 电流的方向

━ 橙色长条 = 电流规定方向：正极 → 负极（正电荷移动的方向）
● 蓝色圆点 = 电子（带负电）实际移动：负极 → 正极，与电流方向相反
富兰克林规定：正电荷从电源正极流向负极的方向为电流方向。后来发现金属中是电子在移动，电子从负极流向正极，与规定的电流方向相反。

4.3 什么是电压？

要让一段电路产生电流，两端必须有电压（两点间的电势差）。电源就是提供电压的装置。
类比：水泵把水抽得越高，水压越大，水流越快；电源电压越大，电流越大，灯泡越亮。

4.4 什么是电阻？

电阻（R）：导体对电流的阻碍作用。国际单位欧姆（Ω）。
1 kΩ = 10³ Ω　　1 MΩ = 10³ kΩ
相同电压下，电阻越小，电流越大；电阻越大，电流越小。

4.5 电压、电流及电阻的关系

4.6 电路中的元件怎样连接？

用电器的两种基本连接方式：串联（依次相连成一串）与并联（两端分别连在一起）。每个灯泡电阻 6 Ω，电源 6 V。

串联 vs 并联

串联I = I₁ = I₂
V = V₁ + V₂
R = R₁ + R₂
一条路径，开关位置不影响控制
并联I = I₁ + I₂
V = V₁ = V₂
1/R = 1/R₁ + 1/R₂
干路开关控全部，支路开关只控本支路
📖 推导：串联总电阻V = V₁+V₂，IR = IR₁ + IR₂，故 R = R₁ + R₂。
📖 推导：并联总电阻I = I₁+I₂，V/R = V/R₁ + V/R₂，故 1/R = 1/R₁ + 1/R₂，总电阻小于任一支路电阻。
