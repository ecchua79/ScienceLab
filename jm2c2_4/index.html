化学反应
的奇妙世界

1856年，一个意外的发现改变了世界——
英国化学家 威廉·珀金（William Perkin） 在研究疟疾药物时，无意中将一些原料混合，烧瓶中出现了一种美丽的 紫色物质。这就是世界上第一种人工合成染料——苯胺紫。从此，普通人也能穿上紫色衣服，紫色不再是皇室专属。这一切，都源自于化学反应。

物质变化

物质的变化分为两大类。了解概念后，点击下方例子进行分类练习！

🧊
物理变化 Physical Change
物质只发生温度、颜色、状态、形态等变化，但没有产生新物质。大多数物理变化是可逆的。

关键词：三态变化、热胀冷缩、溶解
🔥
化学变化 Chemical Change
物质在发生变化后有新物质产生。与物理变化不同，化学变化很难逆转。

关键词：燃烧、生锈、发光、沉淀

2.2

化学反应

化学变化也称为化学反应。点击每个现象卡片，了解它的含义与例子。

在化学反应中：参与反应的物质称为 反应物 (reactant)，形成的新物质称为 生成物 (product)。

化学反应常见的现象 —— 点击卡片展开

💡
发光
反应过程中有光能释放。
例：镁条燃烧、蜡烛燃烧
🔥
发热
反应放出热量，周围温度升高。
例：木炭燃烧、金属与酸反应
🎨
颜色改变
生成物颜色与反应物不同。
例：铁生锈变红棕色、铜氧化变绿
☁️
产生沉淀
溶液中生成不溶于水的固体。
例：CO₂通入石灰水生成CaCO₃↓
💨
产生气泡
反应产生气体逸出溶液。
例：碳酸钙与盐酸反应产生CO₂↑
❄️
温度下降
吸热反应导致周围温度降低。
例：氢氧化钡与氯化铵反应

化学方程式

用化学方程式简洁地表达化学反应的反应物、生成物和反应条件。

📝
文字方程式
用中文名称表达：
碳 + 氧气 点燃→ 二氧化碳
左边 = 反应物 ｜ 右边 = 生成物
⚗️
化学方程式
用化学符号表达：
C + O₂ 点燃→ CO₂
每1个C原子 + 1个O₂分子 → 1个CO₂分子

📋 化学方程式常用符号

符号名称含义例子
+加号表示"和"，连接反应物或生成物C + O₂
→反应箭号"反应后生成"，方向不可逆→ CO₂
点燃 / △ / 高温反应条件写在箭号上/下方，表示所需条件催化剂、通电等
↑气体符号反应物无气体，生成物中有气体产生时CaCO₃ → CaO + CO₂↑
↓沉淀符号溶液反应中生成固体沉淀时CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O

质量守恒定律

化学反应前后，反应物的总质量等于生成物的总质量。为什么？

🏛️ 历史发现：1756年，俄国化学家 洛蒙诺索夫 将锡放在密闭容器中煅烧，发现容器内物质总质量在反应前后不变，从而提出质量守恒定律。

四大反应类型

掌握规律，就能由反应物推知生成物！点击各类型查看详情。

A + B → AB  ｜  多种物质 → 一种物质（多变一）
化合反应：两种或两种以上物质反应，生成一种新物质。常见于燃烧、酸碱的形成。
金属在空气中燃烧
2Mg + O₂ →[点燃] 2MgO

非金属在空气中燃烧

CaO + H₂O → Ca(OH)₂

氮气与氢气合成氨
N₂ + 3H₂ →[高温高压] 2NH₃
重要工业合成反应（哈伯法）
AB → A + B  ｜  一种物质 → 多种物质（一变多）
分解反应：一种物质分解为两种或多种较简单的物质。通常需要提供能量（加热或通电）。
碳酸盐加热分解
CaCO₃ →[△] CaO + CO₂↑

2H₂O →[通电] 2H₂↑ + O₂↑

置换反应：一种单质与一种化合物反应，生成另一种单质和另一种化合物。活动性强的金属可置换活动性弱的金属。
铁与硫酸铜溶液

复分解反应：两种化合物相互交换成分，生成两种新化合物。反应通常在有沉淀生成（↓）、气体逸出（↑）或水生成时才能进行。

氧化作用

氧化作用（oxidation）是指物质与氧气结合形成化合物的过程。根据速度分两类：

铁生锈：4Fe + 3O₂ + 6H₂O → 4Fe(OH)₃，之后 4Fe(OH)₃ → 2Fe₂O₃ + 6H₂O
🐌 缓慢氧化 Slow Oxidation
进行缓慢，无明显发光发热

反应速度非常缓慢，不产生明显的光和火焰，但有热量缓慢释放。

铁生锈 食物腐败 木材腐烂 铜绿形成
4Fe + 3O₂ → 2Fe₂O₃（简化）
⚡ 剧烈氧化 Rapid Oxidation（燃烧）
反应迅速，产生大量光和热

反应激烈，通常伴随明火、高温、发光，即我们看到的燃烧现象。

木炭燃烧 镁条燃烧 蜡烛燃烧 汽油燃烧

2.5

燃烧与灭火

燃烧是一种剧烈的氧化作用。燃烧的发生需要同时满足三个条件——缺一不可！

🔥 燃烧三要素（点击条件开启/关闭）

🪵 ① 可燃物 已开启

必须有可以燃烧的物质：天然气、汽油、煤、木材、纸张等。没有可燃物，燃烧不会发生。

💨 ② 充足的助燃物（氧气） 已开启

充足的氧气供应对燃烧至关重要。氧气是最常见的助燃物。

🌡️ ③ 达到燃点（着火点） 已开启

温度必须达到可燃物的燃点。白磷≈40°C，红磷≈200°C，木材≈250°C。

🔥 正在燃烧！

三个条件全部满足，燃烧正在进行。

💧 灭火原理（点击查看）

💧
浇水灭火
水吸收大量热量，使温度降到燃点以下；水蒸气同时隔绝氧气。
消除：温度 + 隔绝氧气
🍳
盖锅盖（油锅）
锅盖隔绝空气，切断氧气供应，火焰熄灭。
消除：助燃物（氧气）
🌲
防火带（森林）
砍除防火带内的树木枯枝，去除可燃物，阻止火势蔓延。
消除：可燃物
🧯
干粉灭火器
喷出的干粉覆盖燃烧物，隔绝氧气并吸热降温，适用于多种火灾。
消除：助燃物 + 温度
