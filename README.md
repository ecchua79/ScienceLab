## 📖 项目简介

本仓库收录了初一（JM1）、初二（JM2）、初三（JM3）科学课程中，配合董总2025年为初中科学课程纲要设计的**互动实验网页**——涵盖物理、化学、生物三大领域，共 28 个章节、90+ 个独立的互动游戏 / 模拟 / 笔记页面。
由于2027年的初三新课本尚未取得，所以目前只尝试做了一个，有待扩展。
其他内容也会随时扩展或更新，以配合教学使用。
所有内容都以 `index.html` 作为总控制台入口，学生打开即可按年级、章节快速跳转到对应的互动学习内容。

- 🎮 每个章节都有对应的 **互动游戏 / 3D 模拟 / 闯关挑战**
- 📓 每个章节都附带一份 **互动实验笔记**，作为课堂讲解辅助
- 🌌 首页采用「光谱控制台」视觉设计，把三个年级视为光谱上不同的波段

## 🖥️ 在线预览 / 使用方法

**方式一：本地打开（推荐用于课堂离线环境）**

```bash
# 克隆仓库后，直接用浏览器打开
open index.html          # macOS
start index.html         # Windows
```

**方式二：GitHub Pages 部署**

1. 进入仓库 `Settings → Pages`
2. Source 选择 `main` 分支 / 根目录
3. 保存后访问 `https://<你的用户名>.github.io/<仓库名>/`

> ⚠️ 所有页面均为**纯前端单文件**，不依赖任何外部 CDN 或后端服务，即使在没有网络连接的电脑教室也能正常运行。

## ✨ 首页设计特色

`index.html` 总控制台采用「光谱 SPECTRUM」为设计主题：

- 🌈 顶部**波长扫描条**：四个年级对应光谱上四段波长，一眼看清学习进度分布
- 🔍 **即时搜索**：输入章节或游戏名称，实时过滤卡片
- 💠 每章节按学科属性配色（热=红橙、光=金黄、生命=绿、太阳系=靛蓝……），悬停发光高亮
- 🌌 动态星尘背景 + 极细网格线，营造实验室控制台氛围
- ♿ 支持 `prefers-reduced-motion`，键盘可访问（focus-visible）
- 📱 响应式布局，手机 / 平板 / 电脑均可正常使用

## 🛠️ 技术栈

- 纯 **Vanilla HTML / CSS / JavaScript**（无框架、无构建工具）
- Canvas API（背景动画）、Pointer Events API（部分拖拽题型）、Web Audio API（部分游戏音效）
- 部分模拟使用 **Three.js** 实现 3D 演示
- 字体全部使用系统内建字体族回退（PingFang SC / Microsoft YaHei / Heiti SC），无需联网加载

---

## 🎯 设计原则

- **离线优先**：不依赖任何外部网络请求，适合电脑教室 / 无网络课室
- **单文件封装**：每个游戏都是独立自包含的 HTML 文件，方便老师单独分享或投影
- **即学即测**：每章节都同时提供「互动笔记」与「互动游戏」两种形式，兼顾讲解与巩固
- **可重复挑战**：多数游戏包含分数、连击、限时机制，鼓励学生反复挑战刷分
