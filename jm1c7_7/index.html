光的传播特点

光是一种能量形式。真空中光速约 3×10⁸ m/s，在不同介质中速度不同。光在均匀介质中沿直线传播，这一特性解释了影子、小孔成像等现象。

🔑 核心知识

⚡
光速：真空中 c ≈ 3×10⁸ m/s（每秒约30万公里），是宇宙中最快的速度。在水中约为 3c/4，在玻璃中约为 2c/3。
➡️
直线传播：光在同一均匀介质中沿直线传播，可用带箭头的光线表示。
🌑
影子：不透明物体阻挡光，后方形成影子，这是光不能绕弯传播的直接证据。
📷
小孔成像：光穿过小孔在另一侧形成倒立的实像，原理即光的直线传播。

站 02 / 06
光的反射

光照射到物体表面时会发生反射。根据表面粗糙程度，分为镜面反射和漫反射。两者都遵守反射定律。

🔑 核心知识

📐
反射定律：入射线、反射线、法线三线共面；入射角 i = 反射角 r；光路可逆。
🪞
镜面反射：光滑表面（镜子、平静水面）将平行光线平行反射，形成强烈光亮区域。
🧱
漫反射：粗糙表面（黑板、墙壁、纸张）将光线向各方向散射，使物体从各角度均可见。

站 03 / 06
平面镜与球面镜

镜子分平面镜和球面镜。平面镜成等大虚像；凸面镜成正立缩小虚像；凹面镜可聚光，可成实像。

🔑 核心知识

🪞
平面镜：成等大、正立、虚像，像距 = 物距，图像左右对换（横向倒置）。
🔵
凸面镜：反射面向外弯曲，虚焦点，成正立缩小虚像，扩大视野 → 汽车后视镜、广角镜。
🔴
凹面镜：反射面向内弯曲，实焦点，可汇聚光线 → 手电筒反光杯、太阳能聚热器；近距成正立放大虚像。

站 04 / 06
光的折射

光从一种介质斜射入另一种时传播方向改变，称折射。光从光密射出光疏，角度超临界角时，发生全反射。

🔑 核心知识

🌊
折射定律：入射线、折射线、法线共面；光从光疏→光密（如空气→水），折射角 < 入射角，偏向法线。
👁️
视深度：水中物体看起来比实际更浅，是折射造成的视错觉（表观深度 < 实际深度）。
💡
全反射：光从光密→光疏（如水→空气），入射角 > 临界角时，光被完全反射，无折射光。
🔗
光导纤维：利用全反射原理，光在玻璃芯中不断全反射，用于通讯与内窥镜。

站 05 / 06
透镜成像

透镜利用折射改变光线方向。凸透镜汇聚光线，凹透镜发散光线。物体位置决定成像性质。

🔑 核心知识

🔍
凸透镜：物在 2F 外→倒立缩小实像；F~2F 间→倒立放大实像；焦点内→正立放大虚像（放大镜）。
👓
凹透镜：任何位置均成正立缩小虚像，用于矫正近视眼。
📏
透镜公式：1/f = 1/do + 1/di，f 为焦距，do 为物距，di 为像距。

站 06 / 06
光的色散与颜色

1666年牛顿用棱镜证明白光由多种颜色组成。物体颜色取决于其反射（不透明）或透过（透明）的光色。

🔑 核心知识

🌈
色散：白光经棱镜分解为红橙黄绿蓝靛紫，紫光偏折最大，红光偏折最小。
🔴
不透明物体颜色：由反射的光决定。红花反射红光；黑色物体吸收所有颜色。
🟢
透明物体颜色：由透过的光决定。绿色玻璃只让绿光通过。
💡
光的三原色：红＋绿＋蓝 = 白光；红+绿=黄，绿+蓝=青，红+蓝=品红。
