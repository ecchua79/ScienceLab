6.1

什么是酸？什么是碱？

在日常生活中，我们经常接触到酸和碱。柠檬汁、食醋是常见的酸；肥皂、牙膏是常见的碱。但从化学角度，酸和碱的本质是什么？

🍋 酸 (Acid)

在水中电离后能产生氢离子 (H⁺) 的化合物称为酸。

常见例子：盐酸 (HCl)、硫酸 (H₂SO₄)、硝酸 (HNO₃)、柠檬酸、碳酸

🧼 碱 (Alkali)

在水中电离后能产生氢氧根离子 (OH⁻) 的化合物称为碱。

常见例子：氢氧化钠 (NaOH)、氢氧化钾 (KOH)、氢氧化钙 Ca(OH)₂

盐 (Salt)

在化学中，盐是由金属离子（或铵根离子 NH₄⁺）与酸根离子组成的化合物。食盐（NaCl）只是其中一种！

Na₂CO₃ 碳酸钠
CuSO₄ 硫酸铜
NH₄NO₃ 硝酸铵
NaCl 食盐

6.2

酸和碱的通性

由于酸电离产生的阳离子全为 H⁺，碱电离产生的阴离子全为 OH⁻，因此各种酸（碱）具有相似的共同性质——通性。点击展开各项通性：

🍋 酸的通性

酸能使紫色石蕊试液变红色，而不能使无色酚酞试液变色（酚酞在酸中无色）。

酸能与活泼金属（如铁、锌）反应，生成相应的盐和氢气。

Fe + 2HCl → FeCl₂ + H₂↑

💡 铁钉放入盐酸中会有气泡冒出，就是产生了氢气。

酸能与金属氧化物反应，生成相应的盐和水。工业上用来去除铁锈（铁锈的主要成分是 Fe₂O₃）。

6HCl + Fe₂O₃ → 2FeCl₃ + 3H₂O

酸与碳酸盐反应会产生二氧化碳气体。将鸡蛋壳（碳酸钙）放入盐酸中，会看到气泡冒出。

2HCl + CaCO₃ → CaCl₂ + H₂O + CO₂↑

酸与碱发生中和反应，生成盐和水。

HCl + NaOH → NaCl + H₂O

🧼 碱的通性

碱能使紫色石蕊试液变蓝色，使无色酚酞试液变红色。

碱能与某些盐发生反应，生成新的盐和新的碱。

2NaOH + CuSO₄ → Na₂SO₄ + Cu(OH)₂↓

（会生成蓝色的氢氧化铜沉淀）

碱能与某些非金属氧化物（如 CO₂、SO₂）反应，生成盐和水。工业上用此原理减少废气排放。

Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O
SO₂ + 2NaOH → Na₂SO₃ + H₂O

6.2.2

中和反应的生活应用

中和反应在日常生活、农业和工业中应用广泛：

💊

治疗胃酸过多

氢氧化铝药液利用碱性中和胃里过多的盐酸，缓解不适。

Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O
🦟

蚊虫叮咬止痒

蚊虫分泌蚁酸（甲酸），涂抹小苏打（碳酸氢钠）碱性溶液可中和，减轻痛痒。

HCOOH + NaHCO₃ → 中和反应
🌾

改良酸性土壤

农夫施加熟石灰（氢氧化钙）中和过酸的土壤，改善农作物生长环境，提高产量。

Ca(OH)₂ + H₂SO₄ → CaSO₄ + 2H₂O
🏭

处理工业废水

工厂用碱来中和酸性工业废水，减少对环境的污染。

酸性废水 + NaOH → 中性盐 + H₂O
🌫️

减少空气污染

工厂废气中的 SO₂ 通过氢氧化钠溶液，大大减少二氧化硫的排放量。

SO₂ + 2NaOH → Na₂SO₃ + H₂O
⚗️

石油工业精炼

利用 NaOH 溶液中和石油产品经硫酸洗涤后残余的酸性物质，得到最终成品。

酸性残余 + NaOH → 盐 + H₂O

6.3

安全使用酸和碱

强酸（HCl、H₂SO₄、HNO₃）和强碱（NaOH、KOH、Ca(OH)₂）具有强烈腐蚀性。点击每张卡片，判断操作是否正确！

🥽

佩戴安全眼镜

使用强酸强碱时戴好护目镜

🚰

把水倒入浓酸

稀释浓酸时将水倒入酸中

🧤

佩戴防护手套

处理腐蚀性化学品时戴手套

💧

大量清水冲洗

皮肤沾上强酸强碱后立刻用流动清水冲洗10–15分钟

🍷

用嘴吹散气味

直接将脸凑近容器嗅闻酸液

🏺

专用容器储存

将强酸强碱储存在专用标记的容器中

⚠️ 稀释浓酸的正确操作

应将浓酸慢慢沿烧杯内壁倒入水中，同时用玻璃棒不断搅拌散热。

❌ 绝不能将水倒入浓酸！

水的密度比浓酸小，会浮在表面迅速沸腾，导致酸液飞溅，引发危险。

🆘 急救措施

沾上强酸
① 大量流动清水冲洗 10–15 分钟
② 再用小苏打溶液（碳酸氢钠）冲洗
③ 严重时立即就医
沾上强碱
① 大量流动清水冲洗 10–15 分钟
② 再用食醋冲洗
③ 严重时立即就医
