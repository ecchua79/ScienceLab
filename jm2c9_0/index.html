9.1
什么是简单机械？

机械是能改变力的大小或方向的装置。最基本的机械称为简单机械，一切复杂机器都由它们组成。

⚖️
杠杆 Lever
在力的作用下能绕固定点转动的硬棒。生活中无处不在：剪刀、开瓶器、镊子……
🔄
滑轮 Pulley
周边有槽、可绕中心轴转动的轮子。定滑轮改变力的方向，动滑轮省力。
🛞
轮轴 Wheel & Axle
由大小不同的两个圆盘组成。古代辘轳利用轮轴省力，将沉重水桶提起。
📐
斜面 Inclined Plane
沿斜面移动物体比直接举高省力，但增加了位移距离。螺旋是变形的斜面。
🔩
螺旋 Screw
将斜面盘绕在有限空间，较小的旋转力能产生较大的推进力。
🪓
楔子 Wedge
由两个斜面组成，将向下的力转化为水平分力，用于劈开或固定物体。
🏛️ 科学发现：古代简单机械的智慧
汉代发明的水碓舂米机结合了杠杆和凸轮原理，用水力驱动，大大提高粮食加工效率。 古人发明的石碾利用杠杆原理，让谷物去皮变得轻松。这些发明比现代机器早了数千年！

理解杠杆，先认识五个核心概念，再掌握三种分类。

📍

Fulcrum
支点 Fulcrum
杠杆绕之转动的固定点。它既不移动，也不产生力。一切都围绕它旋转。
💪

🪨

📏

📐

阻力臂 l₂

✅ 省力杠杆 — 动力臂 > 阻力臂

条件：l₁ > l₂，因此 F₁ < F₂（省力！）
代价：动力作用点移动距离 x₁ > x₂（费位移）

🔧 生活例子：开瓶器、剪铁皮的大剪刀、撬棍、道钉撬、独轮车、跷跷板靠近支点的一侧重物

⚡ 费力杠杆 — 动力臂 < 阻力臂

条件：l₁ < l₂，因此 F₁ > F₂（费力！）
优势：动力作用点移动距离 x₁ < x₂（省位移！）

🔧 生活例子：镊子、筷子、钓鱼竿、扫帚（抓着上端扫地）、人的小腿提起脚跟

⚖️ 等臂杠杆 — 动力臂 = 阻力臂

条件：l₁ = l₂，因此 F₁ = F₂（既不省力也不费力）
特点：精确平衡，常用于测量

🔧 生活例子：天平、跷跷板（等距对称）、杆秤（等臂状态）

类型 条件 力的比较 位移比较 典型应用
省力杠杆 l₁ > l₂ F₁ < F₂（省力） x₁ > x₂（费位移） 开瓶器、撬棍
费力杠杆 l₁ < l₂ F₁ > F₂（费力） x₁ < x₂（省位移） 镊子、筷子

💡 为什么省力杠杆会费位移？
这是能量守恒定律的体现。功 = 力 × 位移。
省力杠杆中：F₁ < F₂，但 x₁ > x₂，使得 W = F₁·x₁ = F₂·x₂。
机械不能凭空创造能量，省力就必须费位移，省位移就必须费力。这就是简单机械的本质。

9.2 应用
人体中的杠杆系统

我们的骨骼和肌肉构成了精密的杠杆系统，让我们完成各种动作。

🤔
点头/抬头
等臂杠杆
支点在颈椎，头颅重量（阻力）与颈后肌肉（动力）大致等臂
💪
弯曲手肘
费力杠杆
支点是肘关节，动力臂（肌肉附着点）远小于阻力臂（手持重物距离），费力但省位移
🦶
踮脚站立
省力杠杆
支点是脚趾，小腿肌肉（动力）的力臂大于身体重力（阻力）的力臂
✂️
咬合牙齿
省力杠杆
支点是颞颌关节，咬肌力臂大于牙齿到支点距离，产生强大咬合力

🔍 生活中的杠杆识别

✂️ 剪刀 — 省力还是费力？›

剪刀有两种：普通剪刀靠近轴（支点）的位置剪东西是省力杠杆（力臂大），而靠近尖端剪则是费力杠杆。理发剪等精细剪刀整体设计为省位移杠杆，让手指小幅运动带来刀刃大幅开合。

🎣 钓鱼竿 — 为什么要做得那么长？›

钓鱼竿是典型的费力杠杆。手握端（动力臂短），鱼线端（阻力臂长）。手需要用较大的力，但换来的是鱼线端极大的移动幅度——轻轻抬手就能将鱼甩到很远的地方。所以钓鱼竿越长，抛线越远！

🔧 扳手 — 为什么手柄要做长？›

扳手是省力杠杆。支点是螺母，手握扳手末端（动力臂最长）。手柄越长，动力臂越大，所需力越小。这就是为什么拧紧的螺栓要用长扳手才好拧开——更长的力臂带来更大的力矩。

🎋 筷子 — 日常中的费力杠杆›

筷子是费力杠杆。手指在靠近顶端处发力（动力臂短），而夹取食物的位置在末端（阻力臂长）。虽然费力，但筷子末端能精准移动很小的距离，适合夹取精细食物。这也是为什么用筷子需要练习——控制费力杠杆比省力杠杆更需要技巧！

📌 定滑轮 = 等臂杠杆

定滑轮的支点在滑轮中心。绳子两端到中心的距离（力臂）相等：l₁ = l₂
→ 根据杠杆平衡：F₁ × l₁ = F₂ × l₂，得 F₁ = F₂
→ 定滑轮不能省力，但能改变力的方向（如升旗时向下拉绳让旗子上升）
→ 位移关系：绳子两端位移相等 x₁ = x₂

🔄 动滑轮 = 省力杠杆

动滑轮的支点在滑轮边缘（固定端绳子的那侧）。
动力臂为滑轮直径 = 2r，阻力臂为半径 = r，所以 l₁ = 2l₂
→ 根据杠杆平衡：F₁ × 2l₂ = F₂ × l₂，得 F₁ = F₂/2
→ 动滑轮能省一半力！但不能改变力的方向（仍需向上拉）
→ 位移关系：绳子自由端移动距离是重物的2倍 x₁ = 2x₂

💡 道钉撬例题（例9-1）重现

铁路检修工用道钉撬，在A点竖直向下施力 200N。
动力臂 l₁ = 120cm，阻力臂 l₂ = 6cm

解：由 F₁l₁ = F₂l₂
F₂ = (l₁/l₂) × F₁ = (120/6) × 200 = 4000 N

如何增大对道钉的力？
在 l₂、F₁ 不变时，增大 F₂ 需要增大 l₁。
① 改变 F₁ 方向，使 F₁ ⊥ OA，此时 l₁ 最大
② 向后移动 F₁ 的作用点，使 l₁ 增大
